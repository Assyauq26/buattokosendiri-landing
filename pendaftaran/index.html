Verifikasi email Anda

Kode sekali pakai dikirim ke email. Gunakan email yang sama untuk melanjutkan instalasi di perangkat lain.

Berlaku 10 menit, maksimal 5 percobaan. Periksa folder spam bila email belum terlihat.

Informasi toko

Siapkan domain dan login dashboard sebelum menghubungkan VPS.

Isi tanpa https:// atau garis miring. Domain harus berbeda dari domain platform.

Arahkan domain ke VPS Anda

Di panel DNS domain, buat atau perbarui record A untuk domain toko dengan nilai IP publik VPS. Jika panel meminta nama relatif, isi @ untuk domain utama atau nama subdomain, misalnya toko.

Hapus record A yang menunjuk ke IP lain atau record AAAA untuk hostname toko tersebut. Pertahankan record email.

Minimal 12 karakter. Gunakan setidaknya tiga jenis karakter dari huruf kecil, huruf besar, angka, dan simbol. Simpan password untuk login setelah instalasi. Password awal dienkripsi selama proses instalasi.

Hubungkan VPS Anda

Gunakan VPS Ubuntu 24.04, minimal 2 vCPU, RAM 2 GB, dan 12 GB ruang kosong. RAM di bawah 4 GB membutuhkan swap sekitar 2 GB.

Jika VPS sudah menjalankan toko dari installer ini, pakai domain toko yang sama untuk menyambungkan kembali.

  1. Masuk melalui ssh USER@IP_VPS, lalu pastikan akun Anda memiliki sudo.
  2. Izinkan port 80 dan 443. Database dan wizard lokal tetap tertutup dari internet.
  3. Buat token pairing, salin perintah, lalu jalankan di terminal VPS.
  4. Tempel token saat terminal memintanya. Token berlaku 15 menit dan hanya untuk toko ini.

Jangan bagikan token atau memasukkannya ke riwayat shell. Tunggu halaman ini mendeteksi agent.
