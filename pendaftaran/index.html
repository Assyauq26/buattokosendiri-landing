Verifikasi email Anda

Kode sekali pakai dikirim ke email. Gunakan email yang sama untuk melanjutkan instalasi di perangkat lain.

Berlaku 10 menit, maksimal 5 percobaan. Periksa folder spam bila email belum terlihat.

Informasi toko

Gunakan domain milik Anda. Informasi dikunci setelah VPS berhasil dipasangkan.

Isi tanpa https:// atau garis miring. Domain harus berbeda dari domain platform.

Password admin dibuat di VPS Anda dan tidak dikirim ke platform.

Hubungkan VPS Anda

Gunakan VPS kosong Ubuntu 24.04, minimal 2 vCPU, RAM 2 GB, dan 12 GB ruang kosong. RAM di bawah 4 GB membutuhkan swap sekitar 2 GB.

  1. Masuk melalui ssh USER@IP_VPS, lalu pastikan akun Anda memiliki sudo.
  2. Izinkan port 80 dan 443. Database dan wizard lokal tetap tertutup dari internet.
  3. Buat token pairing, salin perintah, lalu jalankan di terminal VPS.
  4. Tempel token saat terminal memintanya. Token berlaku 15 menit dan hanya untuk toko ini.

Jangan bagikan token atau memasukkannya ke riwayat shell. Tunggu halaman ini mendeteksi agent.

Aktivitas terakhir

    Pengaturan DNS toko

    Arahkan record A domain toko ke IP VPS yang diberikan penyedia VPS. Periksa AAAA jika IPv6 belum tersedia. Pertahankan record email. Sertifikat HTTPS diperiksa oleh installer setelah DNS sesuai.

    Pencabutan menghentikan komunikasi baru. Operasi lokal yang sudah berjalan dapat menyelesaikan langkahnya. Untuk berhenti segera, jalankan sudo systemctl stop btos-agent di VPS.

    Toko siap dibuka

    Installer telah melaporkan pemeriksaan HTTPS dan kesehatan aplikasi berhasil.

    Masuk pertama kali

    Ambil password admin dari terminal VPS Anda:

    sudo cat /etc/btos-agent/admin-password

    Simpan di pengelola password, ubah password setelah masuk, lalu hapus salinan file tersebut setelah akses baru dipastikan.

    Tambahkan produk dan lengkapi pembayaran serta pengiriman sebelum checkout diaktifkan. Ikuti panduan hingga pesanan pertama.
