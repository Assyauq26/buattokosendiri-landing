Kebijakan Privasi Platform

Versi 2026-11-05.M1 · Berlaku saat platform M1 diaktifkan.

Data dan tujuan penggunaan

Platform menyimpan email seller, waktu dan versi persetujuan, nama toko, domain, email administrator toko, identitas agent, IP publik VPS yang dilaporkan agent, versi rilis, status dan waktu instalasi. Data dipakai untuk autentikasi, menghubungkan VPS milik seller, menjalankan instalasi, dan membantu pemulihan.

Email OTP dan session

Resend memproses alamat email dan pesan OTP untuk pengiriman kode masuk. Kode berlaku 10 menit dengan maksimal 5 percobaan, dan disimpan sebagai HMAC, bukan teks kode. Session memakai cookie HttpOnly, Secure, SameSite=Strict yang berlaku 12 jam. Tombol Keluar mencabut session saat ini. Data login tidak disimpan di localStorage.

Pairing dan batas akses agent

Token pairing berlaku 15 menit dan sekali pakai untuk satu toko. Token disimpan sebagai hash. Agent yang dijalankan dengan sudo pada VPS seller dapat memasang runtime, database, dan aplikasi menggunakan installer resmi. Agent mengirim status operasional, versi, IP publik, dan hasil pemeriksaan kesehatan melalui HTTPS. Platform tidak menerima password SSH, private key, password admin toko, atau isi database pelanggan. Password awal administrator dibuat dan disimpan hanya pada VPS seller.

Seller dapat mencabut komunikasi agent dari wizard. Pencabutan memblokir permintaan agent berikutnya, tetapi operasi lokal yang sedang berjalan dapat menyelesaikan langkahnya. Untuk berhenti segera, jalankan sudo systemctl stop btos-agent di VPS.

Keamanan dan retensi

Database platform terpisah dari database toko. Penghitung pembatasan permintaan memakai HMAC dari identitas/IP dan dibersihkan setelah kedaluwarsa ditambah satu hari. OTP yang kedaluwarsa dibersihkan setelah satu hari; session kedaluwarsa dan token pairing dibersihkan berkala. Data seller dan catatan instalasi disimpan selama diperlukan untuk layanan dengan peninjauan paling lambat 12 bulan. Log aplikasi tidak mencatat isi formulir, kode OTP, atau token. Log jaringan penyedia infrastruktur dapat memproses alamat koneksi.

Akses, koreksi, dan penghapusan

Hubungi m.rifatsyauqii@gmail.com dari email terdaftar dengan subjek “Privasi BTOS”. Jangan kirim password atau kunci rahasia. Operator memverifikasi kepemilikan sebelum koreksi atau penghapusan, termasuk penerapan ulang penghapusan bila backup dipulihkan. Data tidak dijual atau digunakan untuk pemasaran tanpa persetujuan terpisah.

Toko mandiri

Pemilik toko bertanggung jawab terhadap database, pelanggan, produk, pembayaran, pengiriman, domain, serta backup pada VPS sendiri. Pairing bukan akses dukungan SSH umum. Pembaruan aplikasi memerlukan versi rilis yang ditetapkan; agent M1 tidak menerima perintah shell bebas atau pembaruan aplikasi otomatis.
