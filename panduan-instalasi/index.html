01 — DOMAIN

Siapkan domain milik Anda

Pastikan Anda dapat masuk ke panel DNS. Contoh tokoceria.com dalam panduan harus diganti domain yang Anda miliki. Simpan daftar record sebelum perubahan. Jangan memakai domain platform atau Hubify untuk toko seller.

Domain dibutuhkan pada langkah Informasi Toko. Isi tanpa https://, path, atau port. Gunakan email administrator yang bisa Anda akses.

02 — VPS

Pilih VPS kosong

  • Ubuntu 24.04 LTS, x86_64 atau ARM64.
  • Minimal 2 vCPU, RAM kelas 2 GB, dan ruang kosong 12 GB. SSD 40 GB disarankan.
  • RAM di bawah sekitar 4 GB memerlukan swap aktif sekitar 2 GB.
  • Akses sudo, internet keluar, serta TCP 80/443 masuk.
Jangan menggunakan VPS berisi layanan atau database lain. Installer menolak port yang dipakai atau data lama yang tidak dikenali. Biaya domain, VPS, dan layanan pihak ketiga mengikuti penyedianya.
03 — AKSES SERVER

Masuk melalui terminal

Buka PowerShell atau Terminal:

ssh USER@IP_VPS

Ganti USER dan IP_VPS sesuai penyedia. Cocokkan fingerprint host dengan Console penyedia sebelum menerima host baru. Di VPS: 

sudo -v
cat /etc/os-release
nproc
free -h
swapon --show
df -h /var

Tingkatkan spesifikasi bila kurang. Ikuti petunjuk penyedia untuk menambah swap tanpa menimpa file lama. Batasi SSH ke alamat operator. Jangan membuka port 5432, 3000, atau 8787 ke publik.

04 — REGISTRASI

Mulai dari email Anda

Buka buattokosendiri.web.id/pendaftaran. Isi email aktif, baca Kebijakan Privasi, centang persetujuan jika setuju, lalu klik Kirim kode OTP.

05 — OTP

Verifikasi email

Masukkan kode 6 digit dari kotak masuk. Kode berlaku 10 menit dan sekali pakai, maksimal 5 percobaan. Klik Verifikasi & lanjutkan. Jika email belum masuk, periksa spam dan alamat, lalu gunakan Kirim ulang setelah menunggu minimal satu menit. Pengiriman dibatasi per jam.

Jangan bagikan kode. Session berlaku 12 jam. Masuk dengan email yang sama untuk melanjutkan toko tersimpan. Akun seller platform berbeda dari akun administrator toko.

06 — INFORMASI TOKO

Tetapkan identitas toko

Isi nama toko, domain milik Anda, dan email administrator. Klik Simpan & lanjutkan. Periksa ejaan: informasi dikunci setelah pairing. Satu akun seller M1 mengelola satu toko.

07 — PAIRING

Hubungkan VPS Anda

Klik Buat perintah pairing. Perintah bootstrap dan token pribadi ditampilkan terpisah. Token berlaku 15 menit untuk memasangkan satu VPS ke toko ini. Token baru membatalkan token lama yang belum dipakai.

08 — BOOTSTRAP

Jalankan perintah dari wizard

  1. Klik Salin perintah, lalu jalankan di terminal VPS.
  2. Bootstrap memastikan server tidak berisi toko lain, mengunduh agent dengan checksum, lalu meminta token.
  3. Klik Salin token dan tempel ketika terminal meminta token. Input disembunyikan.
  4. Sesudah pairing berhasil, agent berjalan sebagai service. Kembali ke browser.

Jangan memasukkan token ke chat, URL, atau perintah shell. Platform tidak meminta password SSH atau private key. Agent mengambil pekerjaan yang dikenal melalui koneksi HTTPS keluar.

09 — STATUS INSTALASI

Pantau operasi nyata

Halaman Instalasi menampilkan heartbeat, waktu terakhir, dan tahap aktif dari backend. Tidak ada progress bar berbasis waktu. Runtime disiapkan, DNS/HTTPS diverifikasi, lalu installer resmi menjalankan build, database, admin, dan health check. Urutan mengikuti persyaratan keamanan installer lama.

Build pada VPS 2 GB dapat memerlukan beberapa menit. Tab boleh ditutup. Jika heartbeat berhenti, periksa koneksi dan service. Jika gagal, perbaiki penyebabnya lalu klik Periksa lagi / lanjutkan. Jangan menghapus database.

10 — DNS TOKO

Arahkan domain ke VPS seller

  1. Buat A record @ menuju IP publik VPS pada wizard.
  2. Koreksi A lain yang menunjuk server berbeda.
  3. Koreksi AAAA jika IPv6 tidak tersedia pada VPS.
  4. Pertahankan MX, SPF, DKIM, DMARC, dan record email.
  5. Tunggu propagasi dan klik Periksa lagi.
nslookup tokoceria.com 1.1.1.1
nslookup tokoceria.com 8.8.8.8

Installer memeriksa dua resolver, IP VPS, dan challenge HTTP. M1 memasang domain persis yang Anda isi; www tambahan perlu dikonfigurasi terpisah setelah instalasi.

11 — HTTPS

Tunggu sertifikat valid

Setelah DNS benar dan port 80/443 dapat diakses, installer meminta sertifikat dan memverifikasi hostname serta certificate chain. Jika tertahan, periksa firewall cloud/VPS, AAAA, CAA, dan propagasi. Jangan memakai --insecure atau mematikan pemeriksaan TLS.

Selesai hanya ditampilkan setelah agent melaporkan HTTPS valid, aplikasi sehat, dan versi sesuai rilis. Verifikasi juga dari perangkat atau jaringan lain.

12 — DASHBOARD

Masuk sebagai administrator

Klik Buka Dashboard pada Toko Siap. Gunakan email administrator yang Anda daftarkan. Password acak dibuat hanya di VPS: 

sudo cat /etc/btos-agent/admin-password

Simpan di pengelola password, ubah melalui alur akun aplikasi, dan pastikan login baru berhasil. Hapus salinan password awal setelah akses baru dipastikan. Platform tidak menyimpan password toko.

13 — PRODUK

Isi katalog dan tampilan

Lengkapi identitas, logo, deskripsi, dan kontak. Buat kategori dan produk beserta foto, harga, stok, berat, dan variasi yang benar. Publikasikan dekorasi jika diminta. Periksa storefront desktop dan mobile. Toko baru tidak membawa produk atau pelanggan Hubify.

14 — PEMBAYARAN

Lengkapi metode pembayaran

Gunakan metode yang didukung versi rilis. Untuk pembayaran manual, isi bank, nama pemilik, dan nomor rekening. Uji petunjuk pembayaran serta konfirmasi pesanan. Jangan memakai kredensial demo. Jika email pelanggan membutuhkan Resend, gunakan domain pengirim terverifikasi dan kredensial milik toko.

15 — PENGIRIMAN

Pastikan ongkir valid

Isi alamat asal/gudang dan pengiriman. Gunakan ongkir manual jika tersedia pada rilis. Untuk J&T, masukkan kredensial seller sendiri dan mapping wilayah resmi lalu uji tarif. Jangan aktifkan layanan bila tarif atau mapping belum valid. Fitur yang terlihat di Hubify belum tentu tersedia pada rilis installer Anda.

16 — SIAP TRANSAKSI

Periksa sebelum menerima pesanan

  • HTTPS valid, storefront terbuka dari jaringan lain.
  • Admin bisa masuk, katalog aktif, harga dan stok benar.
  • Pembayaran dan pengiriman lengkap; checkout mengikuti aturan aplikasi.
  • Uji keranjang, alamat, ongkir, total, pembayaran, dan status pesanan.
  • Uji email pelanggan dan tampilan mobile.
  • Simpan backup serta prosedur pemulihan.
Instalasi selesai tidak otomatis berarti bisnis siap bertransaksi. Umumkan domain setelah alur bisnis berhasil diuji.

Jika proses terhenti

Gejala Tindakan
OTP tidak masuk Periksa alamat, spam, dan cooldown. Hubungi operator bila email belum dikonfigurasi.
Token kedaluwarsa Buat token baru sebelum pairing. Jangan hapus konfigurasi agent terhubung.
Agent offline Periksa service dan koneksi HTTPS keluar.
DNS/HTTPS menunggu Periksa A/AAAA, firewall 80/443, propagasi, CAA. Lalu Periksa lagi.
Build/migrasi gagal Periksa disk/RAM/swap dan log root-only. Jangan hapus volume; lanjutkan pekerjaan yang sama. 
sudo systemctl status btos-agent
sudo journalctl -u btos-agent -n 50 --no-pager
sudo cat /etc/single-store/operation.log

Jangan membagikan secret atau data pelanggan dari log. Wizard lokal dapat dipakai untuk pemulihan melalui SSH tunnel dengan bantuan operator. Hentikan agent sebelum memakainya dan jangan mengekspos port wizard ke internet.

Backup, update, dan pencabutan

Pertahankan backup/restore bawaan toko dan verifikasi pemulihannya sebelum update. Gunakan versi rilis yang disetujui, bukan HEAD branch. Agent M1 tidak menjalankan update jarak jauh. Tombol Cabut akses agent menghentikan komunikasi berikutnya; untuk berhenti segera jalankan sudo systemctl stop btos-agent.
